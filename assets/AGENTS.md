# 3Dアセットのガイドライン

モデルとモーションの座標系・向き・寸法の決まり。ここを外すと、読み込んだ瞬間に
キャラが倒れる・沈む・巨大化する。取り込み前に確認する。

置き場所の分け方は [`README.md`](README.md) を参照する。

## 座標系と向き

Blender と glTF で軸が違う。書き出し時に変換されるので、**どちらの空間の話をして
いるか**を区別する。

| 空間            | 上方向 | キャラの正面 |
| --------------- | ------ | ------------ |
| Blender の編集  | +Z     | -Y           |
| GLB（書き出し） | +Y     | +Z           |

`export_scene.gltf(export_yup=True)` がこの変換をする。Blenderで「正面 -Y」に
作っておけば、GLBでは「正面 +Z」になる。

ゲーム側のカメラは正面のボスを映す 2.5D固定カメラなので
（[`docs/technical-design.md`](../docs/technical-design.md) §3.1）、
キャラが +Z を向いていればそのまま正面が見える。向きが揃っていないモデルを足す
場合は、ゲーム側で回すのではなく、書き出し前にBlenderで直す。表示側に個別の補正を
積むと、モデルが増えるたびに補正が散らばる。

## 寸法と原点

- **原点は足元**（Y=0が接地面）。腰や重心に置かない
- **単位はメートル**。等身大の実寸で作る
- レスト姿勢は**Aポーズ**

現状のモデル:

| モデル               | 身長（GLB, m） | 原点 | 備考                         |
| -------------------- | -------------: | ---- | ---------------------------- |
| `paypay-daisuke.glb` |          1.902 | 足元 | Blender製                    |
| `dance-daisuke.glb`  |          1.809 | 足元 | Blender製                    |
| `hori-daisuke.glb`   |     正規化 1.0 | 足元 | Mixamo経由。下記の例外を参照 |

### 例外: Mixamo経由のモデル

MixamoのFBXは **cm単位・Z-up** で来るため、`hori-daisuke.glb` はルートノードに
`rotation`（X軸90°）と `scale`（0.01）が乗ったまま残っている。メッシュも実寸メートル
ではなく、身長が約1.0の正規化スケールで入っている。上の規約から外れている。

表示側は立ち姿の高さの実測値（0.762）で見た目のスケールを合わせている
（`src/rendering/character/HoriDaisukeModel.tsx` の `MODEL_STANDING_HEIGHT`）。
**この値は `stand-up` の最終姿勢での高さなので、別のクリップを基準にすると
見た目の身長が変わる。** 前かがみのモーションを既定にすると、その分だけ
キャラが大きくなる。

新しくMixamo経由のモデルを足すときは、Blenderで回転・スケールを適用し、実寸
メートルへ揃えてから書き出す方がよい。表示側に姿勢依存の実測値を持たせずに済む。
既存の `hori-daisuke.glb` をその形へ寄せる場合は、`MODEL_STANDING_HEIGHT` の
扱いも一緒に変える必要がある。

## モーション

Mixamoのリグは `mixamorig:*` の33ボーンで共通なので、モーションはキャラに紐づか
ない。ダウンロード設定と置き場所の使い分けは
[`motions/README.md`](motions/README.md) を参照する。要点だけ:

- **Without Skin** で落とす。With Skin だと1本ごとにメッシュとテクスチャが付いて
  くる
- ロコモーション系は **In Place 版**。ルートモーションが入っていると位置制御と
  干渉する
- ボーン名の集合がベースのリグと**完全に一致**していること。過不足があると、
  そのボーンだけバインドポーズに取り残されて姿勢が壊れる

GLBへまとめる手順は各キャラのREADMEにある。
