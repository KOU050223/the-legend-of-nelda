## 仕様

7,500三角形、制作メッシュ4,018頂点、1スキンメッシュ、16ボーン、11単色マテリアル。GLBは530,264 bytes。UVあり、外部テクスチャ不要。GLBの頂点は法線・UV境界で分割されるため制作メッシュより増える。

BlenderはZ-up・正面-Y、GLBはY-up・正面+Z。身長約1.902、足元原点、メートル想定。リグのレスト姿勢は腕を下げたAポーズ。待機アニメーションは24fps、1〜49フレームの2秒ループ。GLBのクリップ名は `Animation`。

基本的な部位単位のウェイトによる簡易リグ。肘・膝・肩は重なった別形状で、激しい曲げでは継ぎ目や食い込みが見える場合がある。表情用シェイプキーや指ボーン、歩行・攻撃モーションは含まない。既存のMixamoアニメーションにはリターゲットが必要。ゲーム本編の既存ボスモデルは置き換えていない。

## 確認

GLB内が1シーン・1メッシュ・1スキン・16ジョイント・1アニメーションであること、カメラが含まれないこと、全頂点にウェイトがあることを確認。GLBをBlenderへ再読み込みし、13フレーム目の座標が有限で、外観が維持されることをレンダーで確認。ゲームエンジン上の再生は未検証。

## 再制作

`blender/build_character.py` をrfingadam-blenderの `blender_execute_script` から `__file__` を設定して実行する。既存の `Daisuke_GameAsset` シーンがある場合は誤上書きを避けるため停止する。新しいBlenderセッションで実行すると、このディレクトリ内の出力を再生成する。別ワークスペースの既存モデルは素材として使用していない。
