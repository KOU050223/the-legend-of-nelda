# dance-daisuke

提供されたダンス画像を参考に、rfingadam-blenderで制作したゲーム用ローポリキャラクター。横に流した黒髪、細めの黒いサングラス、立ち襟の黒シャツ、短い袖、細身の黒パンツを採用。サングラスはHeadボーンに固定され、頭の動きに追従する。前作の青シャツモデルに近い簡略化した造形。

## 仕様

6,414三角形、制作メッシュ3,373頂点、1スキンメッシュ、18ボーン、12単色マテリアル。GLBは409,212 bytes（約400KiB）。UVあり、外部画像テクスチャ不要。書き出し後の頂点はUVや法線境界で分割される。

BlenderはZ-up・正面-Y、GLBはY-up・正面+Z。身長約1.809、足元原点、メートル想定。レスト姿勢はAポーズ。

アニメーションは `Dance_Loop` の1本。24fps、4秒、GLB上は0〜4秒。参考画像の腕のシルエットを取り入れた独自の簡単なループで、元映像の振り付けを正確に再現したものではない。両足を接地させたまま腕と上体を動かす。Blend上のアクション名は `DanceDaisuke_Loop`（既存データと同名ならBlenderが番号を付加）。

## 使用と制限

GLBをゲームエンジンへ読み込み、`Dance_Loop` をループ再生する。カメラ・照明・床はGLBに含めず、編集用Blendだけに同梱。既存のゲーム画面やキャラクターは置き換えていない。

簡易リグで、肩や衣服は重なった部品を含む。肘・膝は複数ボーンのウェイトで変形するが、別の激しいポーズでは継ぎ目や食い込みの調整が必要。指は手ボーンに固定され、指の個別操作や表情シェイプキーはない。Mixamo互換リグではなく、外部モーションにはリターゲットが必要。

## 検証

- GLBに1メッシュ、1スキン、18ジョイント、1アニメーションがあり、カメラがないことを確認。
- 全制作頂点にウェイトがあることを確認。
- GLBをBlenderへ再読み込みし、全97フレームの変形座標が有限であることと、先頭・末尾の頂点位置が一致することを確認。
- 大きく腕を動かしたポーズを再読み込み後にレンダーして外観を確認。
- 最終GLBの時間範囲が0〜4秒であることを確認。
- ゲームエンジン上の再生は未検証。

## 再制作

`blender/build_character.py` をrfingadam-blenderの `blender_execute_script` で、`__file__` をスクリプトの絶対パスに設定して実行する。既存の `DanceDaisuke_Asset` シーンがある場合は誤上書きを避けるため停止する。新しいセッションでの再実行は、このフォルダ内のBlend・GLB・制作プレビューを再生成する。`glb-dance-check.png` は別途再読み込みして撮影した検証画像。
