## 開き方と編集

- `HORI_V2_BLOCKOUT`: 髪・黒Tシャツ付き上半身。初期カメラは `CAM_Bust_LeftFront45`。
- `HORI_V2_FACE_GRAY`: 同じ編集用ジオメトリを共有する顔確認シーン。髪コレクションを除外し、Workbenchの単色グレーでレンダーする。F12で確認できる。ビューポートの色が残る場合はソリッド表示のカラーを「単一」に切り替える。
- `MODEL_HORI_V2` 内の `GEO_FACE`、`GEO_BODY`、`WARDROBE_TSHIRT`、`HAIR_MAIN` で部位を分離。
- `HD_Head_Cage`: 2,880頂点の頭蓋・顔。細分化モディファイアは保持しているが、表示・レンダーとも無効。
- 耳、Tシャツ、頭髪ベースの厚みモディファイアは未適用。眉・瞼・口の線・襟などは編集可能なカーブ。
- 髪はベース＋前髪10束、側頭部左右各5束、頭頂9束、後頭部7束。主束の編集用メッシュと、非表示の `HAIR_CURVE_GUIDES` を保存。ガイドは変換前の履歴で、メッシュへ自動追従する仕組みではない。
- `REF_9VIEWS` は観察時の混雑を避けるためビューレイヤーから除外している。Outlinerで除外を解除すると参照を表示できる。既存5枚を残し、斜視4枚を追加。9枚ともblend内にパック済み。
- 初期Cube・Camera・Lightも削除せず、元の `Collection` を除外して保持。

## 比率・参照の扱い

Z-up、正面 -Y、キャラクター左 +X、メートル単位、単位倍率1。全身の想定身長を1.0、髪の最高点をZ=1.0としている。今回の実体は腰・手首までの上半身のみで、モデルの実バウンディングボックス高が1.0という意味ではない。

READMEの頭幅0.155は頭高0.135と整合しないため、写真と自然な成人比率を優先し、髪・耳を除く頭幅を約0.088に修正した。首幅は頭との接続に合わせて約0.058～0.092のテーパー。これらは実測値ではない。

主基準は `source-front.png`、筋肉量の補助基準は `source-gym.png`。9視点はすべて画像を確認したが、厳密な三面図としては扱っていない。左後135度画像は右後方のように見え、225度と方向が重複して見える。側面画像の鼻が向く画面方向と、今回の +X/-X カメラ規約にも不一致がある。参照の反転・置換は行わず、左右非対称の根拠には使わない。モデルのLeftカメラは+Xから、Rightカメラは-Xから撮影し、Topは+Zから前方が画面下になる向き。

## 実施した検証と限界

- 保存前に名称・部位別コレクション・単位・軸を確認。再読み込み後にも確認。
- 元参照ファイルのSHA-256一致。既存参照5オブジェクトの画像パス、位置・回転・変換行列一致（最大差0）。除外した参照は一時的に再評価してから行列を比較した。
- 9参照画像のパックと依存ファイル欠落なしを確認。
- モデル内のメッシュ: 16,601頂点、16,132面。カーブ求値後のポリゴン数やゲーム向け予算ではない。
- メッシュ頂点の有限値と面積をチェック。非有限値なし、面積1e-12未満の面なし。水密性やアニメーション用辺流の検証ではない。
- 鼻先の過大な突出、耳の外開き、肩の高さ、Tシャツからの三角筋露出を確認画像から修正。
- GUIスクリーンショット取得はMCP応答のJSON解析エラーで失敗。GUIスクリーンショットの検証成功とは扱わない。工程の再読み込みはMCPで確認し、形状の証拠には実レンダーを使用した。

目元・口元は簡略化した面と輪郭で、写真の歯が見える笑顔は未再現。顔全体の本人らしさは未承認。首と頭の接合に段差、袖と胴の接合に境界が残る。頭髪は主束の体積配置段階で、根元・頭頂のつながり、側頭部の隙間、流れの自然さを次に修正する。肌色は仮色で、写真の質感を再現したものではない。

**UV、リグ、アニメーション、完全な非貫通、ゲームエンジンへの書き出しは未検証。** 手、脚、足、口腔・歯、表情制御は未制作。モデルは部品同士の重なりを含む編集用ブロックアウトであり、完成したゲームアセットとは扱わない。

## 制作スクリプト

`build_blockout_v2.py` はMCPで段階実行した制作関数を保存している。読み込みだけでは制作・保存を実行しない。現在のblendを手で編集することを基本とする。

スクリプトには既存モデルへの再実行・既存納品パスへの上書きを防ぐガードがある。再制作する場合は新しい出力名を設定し、参照工程から `setup_face()` → 顔確認 → `build_body_hair()` → `refine_shoulder_hair()` → `refine_shoulder_slope()` → `refine_chest_coverage()` → 確認 → `save_delivery()` の順に進める。`refine_face()` は初回の旧顔への修正履歴で、現在の `setup_face()` には修正値が入っているため再適用しない。会話中にスクリプトを更新しながら制作したため、旧顔に配置した一部付属面と新規再制作結果は完全な頂点一致を保証しない。採用形状の正本は保存したblend。
