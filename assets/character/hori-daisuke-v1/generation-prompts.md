# 生成プロンプト記録

使用ツール: built-in `image_gen`。入力画像: Image #1（顔・髪・正面）と Image #2（体格・背面補助）。全画像共通: 白背景、正方形、全身、同一成人男性、短い黒髪・不規則な前髪、広い肩・発達した上腕、黒いフィット半袖Tシャツ、暗色パンツ、写実寄りの中立的な3Dモデリング参考。

水平8視点は「orthographic」「同一スケール」「同一カメラ高さ」「45度刻み」を指定し、次の視点を個別生成した。

- `front-0.png`: 正面0°
- `left-front-45.png`: キャラクター左前45°（鼻先は画像右）
- `left-side-90.png`: キャラクター左側90°（鼻先は画像右）
- `left-back-135.png`: 左後135°
- `back-180.png`: 背面180°
- `right-back-225.png`: 右後225°
- `right-side-270.png`: キャラクター右側270°（鼻先は画像左）
- `right-front-315.png`: 右前315°（鼻先は画像左）

`top-90.png` は初回生成が斜視だったため破棄し、「カメラは真上、真正面の顔を見せない、水平線なし、人物の正面は画面下」を強調して再生成した。生成された9視点は、側面・背面・頭頂の隠れた情報を補う設計案であり、写真からの厳密な投影ではない。
