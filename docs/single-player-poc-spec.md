# 1人用ボス戦 PoC 仕様書

## 0. このドキュメントの目的

本ドキュメントは、最終的な3人協力ゲームを実装する前段として制作する、**1人用ボス戦PoC** の仕様を定義する。

最終プロダクトでは、

* 見ざる
* 聞かざる
* 言わざる

の3人が1人の勇者を共同操作する。

ただし、最初から3人へ操作・情報を分割するとゲームシステム自体の検証が難しくなるため、まずは

> **1人で操作して普通に成立するボス戦**

を制作する。

その後、この1人が利用していた

* 視覚情報
* 聴覚情報
* 判断
* 操作

を3人へ分解する。

---

# 1. ゲーム概要

## コンセプト

プレイヤーは「睡魔」と戦う勇者を操作する。

ボスのモーションやSEから攻撃を判断し、

* 左回避
* 右回避
* ガード
* 攻撃

を使い分けて戦う。

ボスの攻撃を正しく処理すると反撃チャンスが発生し、攻撃を当てることでボスHPを減らせる。

最終的には、

> **ゲーム内で睡魔を倒す**
>
> ↓
>
> **現実世界で睡魔に負けている人を起こす**

という体験へ接続する予定。

---

# 2. PoCの目的

このPoCでは以下を検証する。

1. ボス戦単体でゲームとして成立するか
2. 攻撃予兆を「見る・聞く」ことで判断する体験が成立するか
3. 回避・ガード・反撃のテンポが気持ちいいか
4. 後から三猿の3人へ情報と操作を分割できる構造になっているか
5. 60〜90秒程度のデモとして成立するか

---

# 3. プレイヤー操作

PoCでは操作を4種類に限定する。

| 操作  | 内容               |
| --- | ---------------- |
| 左回避 | 左方向へスウェー         |
| 右回避 | 右方向へスウェー         |
| ガード | 正面攻撃を防ぐ          |
| 攻撃  | ボスへの通常攻撃 / カウンター |

複雑なコンボ・ジャンプ・アイテム・スキル等はPoCでは実装しない。

---

# 4. 勝敗条件

## 勝利条件

ボス「睡魔」のHPを0にする。

ただし最終フェーズでは、HPを削り切るだけではなく、

> **最終ふかふか布団をカウンターする**

ことでFINISHさせてもよい。

---

## 敗北条件

`HORI SLEEPINESS` が100%になると敗北。

プレイヤーが攻撃を受けるたびに眠気が上昇する。

### 被弾時の眠気増加

| 攻撃     | SLEEPINESS |
| ------ | ---------: |
| 枕薙ぎ払い  |     +10〜15 |
| あくび衝撃波 |     +15〜20 |
| ふかふか布団 |     +25〜30 |

初期値や細かい数値はプレイテストで調整する。


# 6. ボス攻撃

PoCでは3種類のみ実装する。

---

## 6.1 枕薙ぎ払い

### 概要

巨大な枕を右または左から横薙ぎする基本攻撃。

### プレイヤーが判断する情報

**視覚**

* ボスが右腕 / 左腕を大きく引く
* 上半身も攻撃方向へひねる
* 攻撃方向を視覚的に判断できる

**聴覚**

* 「ブォォォ……」という風切りSE
* 攻撃直前に音程が上がる

### 正解行動

```text
右から攻撃 → 左回避
左から攻撃 → 右回避
```

### 成功時

```text
PERFECT DODGE
```

ボスが体勢を崩し、約1.5秒の反撃チャンス。

### 失敗時

* 枕が直撃
* プレイヤーがよろける
* `HORI SLEEPINESS +10〜15%`

---

# 7. 枕薙ぎ払い アニメーション

## 構え

約0.5秒。

* 枕を右または左に構える
* 上半身を大きくひねる
* 布団・枕が擦れる小さなSE

## 溜め

約0.7〜1.0秒。

* 枕をさらに後方へ引く
* 風エフェクトが強くなる
* 風切りSEの音程が徐々に上がる

## 発動

約0.3〜0.4秒。

* 枕を大きく横薙ぎ
* 攻撃判定
* 枕の軌跡エフェクト
* 軽いカメラシェイク

## 硬直

約1.5秒。

* ボスが振り切って前のめりになる
* 反撃可能状態
* 弱点部分を軽く発光

---

# 8. あくび衝撃波

## 概要

ボスが大きく息を吸い込み、眠気を伴う衝撃波を正面へ放つ。

### プレイヤーが判断する情報

**視覚**

* 前屈みになる
* 口を大きく開く
* 胸・腹が膨らむ
* 睡眠エフェクトが口元へ集まる

**聴覚**

```text
スゥゥゥゥ……
```

という吸気音。

徐々に音程が上がり、

**発射直前の約0.15秒だけ無音になる。**

### 正解行動

```text
無音になった直後にガード
```

### 成功時

```text
JUST GUARD
```

* 衝撃波を防ぐ
* ボスが息切れ
* 約2秒の反撃時間

### 失敗時

* 画面が少し暗くなる
* 彩度低下
* プレイヤーがふらつく

```text
DROWSY!
HORI SLEEPINESS +15〜20%
```

---

# 9. あくび衝撃波 アニメーション

## 構え

約0.5秒。

* 口元を押さえる
* 猫背になる
* 薄い睡眠粒子

## 溜め

約1.3〜1.5秒。

* 大きく息を吸う
* 胸・腹が膨らむ
* 睡眠粒子が口元へ吸い込まれる
* 吸気SEの音程が上昇

最後の約0.15秒だけ無音。

## 発動

約0.4〜0.5秒。

* 大あくび
* 正面へ眠気衝撃波
* 空間歪み
* 軽いブラー

## 硬直

約2秒。

* ボスが咳き込む / 息切れ
* 前かがみになる
* 反撃チャンス

---

# 10. 究極奥義・ふかふか布団

## 概要

巨大な布団を召喚し、プレイヤーを包み込もうとする大技。

この技のみ、

> **回避 → カウンター**

という2段階入力を要求する。

### プレイヤーが判断する情報

**視覚**

* 背景が暗くなる
* 巨大布団召喚
* 布団を右または左に構える
* 攻撃方向が分かる

**聴覚**

* 専用ジングル
* 低い寝息SE
* 攻撃直前に「ポフッ」という特殊音

### 第1段階：回避

```text
右から布団 → 左回避
左から布団 → 右回避
```

### 第2段階：カウンター

回避成功後、

```text
0.8秒以内に攻撃
```

### 成功時

プレイヤーが布団を殴り返す。

布団がボス自身に被さり、

```text
COUNTER!
```

ボスが大ダウン。

約2.5〜3秒の最大反撃チャンス。

### 回避失敗時

布団に包み込まれる。

```text
GOOD NIGHT
HORI SLEEPINESS +25〜30%
```

### 回避成功・カウンター失敗

ダメージは受けない。

ただし大ダウンは発生せず、そのまま次の攻防へ移行する。

---

# 11. ふかふか布団 アニメーション

## 構え

約0.7秒。

* ボスが一歩後退
* 両腕を広げる
* BGMを一時的に小さくする
* 背景暗転
* 布団召喚

必要なら画面中央に一瞬、

```text
ULTIMATE
```

を表示する。

## 溜め

約1.5〜1.8秒。

* 布団を右 / 左へ構える
* 布団が膨らむ
* 睡眠粒子
* 寝息SE

## 発動

約0.5〜0.6秒。

* 巨大布団を画面手前へ叩きつける
* 大きな風圧
* 回避判定

## カウンター受付

回避成功後0.8秒。

* ボスが無防備
* 布団部分に小さな光
* UIで「ATTACK NOW」のような答えは表示しない

## 大ダウン

カウンター成功時。

* 布団がボスに被さる
* ボスが転倒
* 足だけ出すなどコミカルな演出
* `Zzz...`
* 約2.5〜3秒反撃可能

# 12. 入力受付

## 回避

基本受付時間：

```text
着弾 -0.6秒 ～ +0.1秒
```

攻撃によって調整可能。

## ガード

あくび衝撃波：

```text
着弾 -0.7秒 ～ +0.1秒
```

## 布団カウンター

```text
回避成功後 0.8秒以内
```

# 13. 入力ミス処理

## 早押し

受付時間より早く入力。

* 無効
* 約0.3〜0.5秒硬直

```text
TOO EARLY
```

## 遅すぎる

被弾。

## 方向ミス

被弾。

## 技選択ミス

基本的に被弾。

例：

* 枕にガード
* あくびに左右回避

## 連打対策

最初の入力のみ採用。

回避後、

```text
約0.7秒 再入力不可
```

## 攻撃連打

反撃可能時間外の攻撃は空振り。

```text
WHIFF
```

約0.4秒硬直。

# 23. 将来の3人協力への分解

このPoC完成後、1人が行っている処理を3人へ分割する。

## 🙈 見ざる

想定：

* 移動担当
* 視覚情報を制限
* ボス攻撃SEなどの音情報を担当

## 🙉 聞かざる

想定：

* 剣 / 盾 / 攻撃担当
* 視覚情報を担当
* ゲーム音や他プレイヤー音声を制限

## 🙊 言わざる

想定：

* 照準 / カメラ / 特殊能力
* 情報の統合担当
* 発話禁止
* ジェスチャー等で伝達

想定通信：

```text
🙈 見ざる
   ↓ 声
🙊 言わざる
   ↓ ジェスチャー
🙉 聞かざる
   ↓ 声
🙈 見ざる
```

情報が循環して初めて1アクションを成立させる。

# 28. 実装上の重要事項

最重要なのは、

> **ゲームロジックと情報提示を分離すること。**

例えば、

```text
BossAttack
↓
AttackType
↓
VisualCue
AudioCue
HitTiming
WeakPoint
```

のように扱う。

「攻撃が発生したからSEを直接鳴らす」のではなく、

```text
Attack Event
↓
Audio Cue Event
```

のように分ける。

そうしておくことで3人協力版で、

```text
見ざるにはAudioCueのみ
聞かざるにはVisualCueのみ
言わざるにはWeakPoint情報
```

のように配信先を切り替えやすくする。
